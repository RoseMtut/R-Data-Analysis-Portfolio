# Iris Dataset Analysis

# Project Overview

This project is part of my practical learning in R programming and data analysis. I used the Iris dataset to explore the characteristics of different iris flower species and practise working with data in R.

The analysis focuses on exploring the dataset, understanding relationships between variables and using visualisations to communicate patterns in the data.

# Objectives

Explore the structure and characteristics of the Iris dataset.

Examine differences between flower species.

Practise basic statistical analysis in R.

Develop data visualisation skills.

Interpret patterns and relationships within the dataset.

# Tools Used

R

RStudio

Iris dataset

# Analytical Techniques

Data inspection and exploration.

Descriptive statistics.

Data visualisation.

Comparison of measurements across species.

# Dataset

The Iris dataset contains measurements of three iris flower species:

Setosa

Versicolor

Virginica

The measurements include sepal length, sepal width, petal length and petal width.
