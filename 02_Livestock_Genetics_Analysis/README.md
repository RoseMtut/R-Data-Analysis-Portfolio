# Livestock Genetics Data Simulation and PCA Analysis

# About the Project

I developed this project as part of my practical learning in R programming and data analysis, with a particular interest in livestock genetics and agricultural research.

Using R, I created a simulated dataset representing 100 livestock records. The dataset includes animal characteristics, production-related measurements, genetics-related variables and farm regions.

I then explored the data using summary statistics, prepared selected numerical variables for analysis and applied Principal Component Analysis (PCA). 

I also used visualisations to examine relationships between variables and identify patterns within the simulated dataset. This project gave me an opportunity to practise working through different stages of a data analysis process, from generating and exploring data to performing statistical analysis and presenting results visually.

# What I Wanted to Explore

Through this exercise, I aimed to:
Create and work with a structured livestock dataset.
Explore animal and production-related variables using descriptive statistics.
Prepare numerical data for multivariate analysis.
Apply PCA to explore patterns among selected variables.
Examine relationships between variables using correlation analysis.
Present the analysis through clear and informative visualisations.

# About the Dataset

I generated 100 simulated livestock records in R. Each record represents an animal with a set of characteristics.

The dataset includes:

Variable Description

Animal_ID - Unique animal identifier

Breed - Simulated breed category

Weight_kg - Body weight in kilograms

Milk_Production_L - Milk production in litres

Genotype_Score - Simulated genotype-related score

SNP_Count - Simulated SNP count

Health_Score - Simulated health score

Farm_Region - Simulated farm region

The dataset was generated for practice purposes. It does not contain actual livestock measurements or real genotyping data.

# What I Did

The analysis followed these main steps:

Generated a simulated dataset containing 100 livestock records.
Explored the dataset and examined summary statistics.
Selected numerical variables for further analysis.
Standardised the selected variables before PCA.
Performed PCA using the prcomp() function.
Used visualisations to explore the results.
Examined correlations among the selected variables.

# Visualisations

The project includes:

PCA individual plot: Displays the distribution of simulated animal records, coloured according to breed category.
Scree plot: Shows the proportion of variation explained by the principal components.
Variable contribution plot: Illustrates the contribution of variables to the principal components.
Correlation heatmap: Displays correlations among the selected numerical variables.
